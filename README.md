# UH · Interaction Lab

A standalone canvas of pixel-perfect, dev-ready micro-interaction prototypes for the Ultrahuman app, replicated 1:1 from Figma with motion specs for iOS & Android.

Open `index.html` — it's a single self-contained page (no build step). Each section is one interaction with a live prototype and a Motion-spec modal.

**Interactions:** Live Pill · Bio Intelligence · Live Pill V2 (liquid metal) · Activity Detection · Battery Low Notification · Stacked Notifications.
